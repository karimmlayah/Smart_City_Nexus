# Données

Placez ici vos jeux de données vidéo pour entraîner ou évaluer les modèles.

- **Combat** : clips courts étiquetés `fight` / `normal` (vous pouvez adapter `scripts/train_fight.py` pour charger vos fichiers).
- **Foule** : séquences de caméras publiques (respecter les licences).

Pour un démarrage rapide, l’entraînement par défaut utilise des **séquences synthétiques** générées en mémoire.
